# P0–P2 结果报告（最终整理）

## 1. P0 数据准入
GSE164378 配对 PBMC RNA+ADT 原始矩阵经条码、特征和整数计数核验；本轮使用 18,624 个细胞（4 个粗类型、每类 2 个 l2 亚型）。训练供体 P1/P2/P5/P6，验证 P3/P7，测试 P4/P8；donor 与 batch 嵌套关系仍限制跨供体解释。ADT 元数据 nCount 与重算 raw 总量不一致，分析统一使用实际 raw counts；panel 含 isotype，但本轮未做背景扣除。π 是所选四类子池内的细胞份额，s 是粗类型内 l2 条件比例，θ 是 8 个细亚型的整体份额；s 不是连续生物状态。

## 2. P1/P2 运行结果
P1/P2 均为 CPU 的技术伪点评估，不是独立生物样本。P2为2640个伪点×7个诊断臂×4个粗类型=73920类型评估行，18480个spot-arm记录，0求解失败；只有D1与D2_same_donor使用特许输入。以下均为test P4/P8、depth=1/drop=0、场景等权宏平均，π/s/θ8为0–1误差。D3为先joint估π再固定π用RNA估s的两阶段对照，π保持是构造；其s/θ平均低于M4与拼接，但不是每类型都改善。

|模型/臂|π MAE|s MAE|θ8 MAE|
|---|---:|---:|---:|
|M2 fixed RNA+ADT|0.052479|NA|0.033557|
|M3 RNA-only flex|0.146393|0.342443|0.101729|
|M4 RNA+ADT flex|0.045845|0.363051|0.090992|
|Stacked (M4 π + M3 s)|0.045845|0.342443|0.084588|
|D3 stage2 RNA 条件π̂|0.045845|0.284471|0.069160|

M2不估s，其θ由冻结s=.5重构；名义设计与取整后多数粗类s不变或接近该先验，M2平均优势不能推出不估细层普遍最佳。

D1 真π诊断：RNA s=.281254、θ8=.067367；joint s=.378275、θ8=.093114。D2 cross_matched：π=.047413、s=.358716、θ8=.089939；D2 same_donor：π=.020839、s=.179287、θ8=.043844。特许条件不可当部署成绩；数值只作当前设定描述，无显著性检验或生物有效性结论。P1 的 S1 只是名义“只变组成”：极端 delta 时某粗类型仅分到 5 个细胞，取整使真实 s=2/5=0.4（S1 共 20,160 行中 3,360 行）；评分采用实际计数真值，不能称严格独立因素设计。M2 不估 s，其冻结先验优势仅表示多数粗类型真实 s 不变或接近 0.5。类型异质性须逐类型报告。分母为 7 臂×2 split，每臂每 split 1,320 spot，attempted=ok，failed=0；s_support 的 5,280 是粗类型评估条数而非 spot 数。

本轮无空间坐标、未训练 SpaMOT、未运行官方 MICSQTL/DestVI；测试仅两供体，伪点与 seed 为技术重复。7 的独立复核已关闭 B3，复核原件见[review](2026-09-08-p0-p2-execution-review.md)。建议下一轮优先在新供体或独立数据确认D3，补齐模态-only、静态/收缩与可比官方基线；如简单方案仍有明确未解决缺口，再决定动态gate/参考适配新模型投入。均未执行，P3另行批准。一次负结果不证明细层不可识别，也不自动证明神经模型必要。
