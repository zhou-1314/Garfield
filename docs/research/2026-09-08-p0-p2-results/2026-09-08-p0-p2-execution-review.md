### 2.2 ⛔ B-1（正式跑前必补）：罚项近似约束缺“真实跑的残差失败处理”

**这是根侧点名要防的失效模式（exact toy 过、real 违反却仍称“固定 π”）。我的独立数值结果是：风险真实存在但幅度小 —— 正因如此更要把策略前置写死，而不是等看到结果再决定。**

我实测的残差（`max_c|π̂_c−π_c^given|`，ρ = 1e3·‖A‖_F）：

| 情形 | 残差 | 距 1e-6 阈值 |
|---|---|---|
| exact toy（π_given = 真 π，数据一致） | **1.6e-10** | 6000× 余量 |
| 稀有粗类型 π=[.94,.02,.02,.02] / [.97,.01,.01,.01] | 5.1e-10 / 3.8e-10 | 充裕 |
| 高共线性 corr=0.999 | 1.2e-10 | 充裕 |
| **π_given 与数据强冲突**（真 [1,0,0,0] vs given [.5,0,0,.5]） | **5.0e-8** | 20× |
| **最大冲突**（given [0,0,0,1] / [.001,.001,.001,.997]） | **1.07e-7 / 1.35e-7** | **仅 ~7×** |

**ρ 敏感性（最大冲突下）**：ρ=1e1·‖A‖ → **1.07e-3 FAIL**；ρ=1e2·‖A‖ → **1.07e-5 FAIL**；ρ=1e3 → 1.07e-7 ok；ρ=1e4 → 1.07e-9 ok。
⇒ **ρ=1e3 是正确的量级选择，但只比失败点高一个数量级**；且 exact toy 恰是最容易过的情形（比最坏情形好约 1000×）——**只在 toy 上断言 <1e-6 无法代表真实跑**。
⇒ **在我测试的这些情形内**，残差随 π_given 与数据最优解的**冲突程度**增大而增大；深度、计数量级（残差对 y 的缩放精确不变）与共线性在我的测试范围内均未驱动残差。**这不是已证明的普遍结论**，仅为本次压测所见；**不据此对作者提出冲突分层的硬性要求**（超出已冻结的最小 scope）。

**必须在正式跑之前补上（缺任一即 B-1 未解除）**：
1. **定死 ‖A‖ 的范数**：协议只写 `ρ = 1e3·‖A‖`。我实测 ‖A‖_F/‖A‖₂ = **1.49**，改用谱范数会使 ρ² 小 2.2×、残差大 ~2.2×。须明写 Frobenius 或 2-范数。
2. **声明正式跑（非 smoke）的残差容限与超限动作**：现协议只在 §5 smoke 阶段断言 <1e-6，`results_p2.csv` 虽逐行记 `constraint_resid`，但**没有超限时该行怎么办的规则**。须写死：超限 → `status` 取何值、是否进 `failures_p2.csv`、是否排除出 D1/D3 指标（或单列分母）。
3. **报告残差分布而非布尔**：逐 (diagnostic, arm, split) 报 `constraint_resid` 的 **max 与分位数**。（原稿此处曾要求"按冲突程度分层"，按根侧意见**撤回**：超出已冻结最小 scope。）
