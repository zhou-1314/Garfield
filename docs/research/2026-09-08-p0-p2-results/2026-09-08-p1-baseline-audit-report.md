## 3. 指标定义、重构规则与已执行自检

### 3.1 空间维度与数学映射
- **粗大类向量 $\pi \in \Delta^3$ ($C=4$)**: 顺序为 `['B', 'CD4 T', 'CD8 T', 'Mono']`，满足 $\sum_{c=0}^3 \pi_c = 1$。
- **条件亚型比例 $s \in [0, 1]^4$**: 定义为各大类内部主亚型占其所在粗分类的离散条件细胞比例（按离散细胞计数定义）。次亚型条件比例为 $1 - s_c$。
- **细亚型向量 $\theta \in \Delta^7$ ($K=8$)**: 包含 8 种亚型 `[B naive, B memory, CD4 Naive, CD4 TCM, CD8 TEM, CD8 Naive, CD14 Mono, CD16 Mono]`。各大类 $c$ 对应索引 $[2c, 2c+1]$，其映射组合式为：
  $$\theta_{2c} = \pi_c \cdot s_c, \quad \theta_{2c+1} = \pi_c \cdot (1 - s_c)$$
  依定义天然满足树一致性 $\theta_{2c} + \theta_{2c+1} = \pi_c$ 与 $\sum_{k=0}^7 \theta_k = 1.0$。

### 3.2 模型定义与重构方式
- **M1 (RNA fixed) 与 M2 (RNA+ADT fixed)**: 按实验设计**不估计条件亚型比例 $s$**，故分母 $s_{\text{denom}} = 0$ 且 $s_{\text{MAE}} = \text{NA}$（这属于设计配置，不是拟合失败）。细亚型按协议固定对称先验 $s_0 = 0.5$ 重构为 $\hat{\theta}_{2c} = \hat{\theta}_{2c+1} = \hat{\pi}_c \times 0.5$。
- **M3 (RNA flex) 与 M4 (RNA+ADT flex)**: 自由拟合 8 维细亚型，聚合得到 $\hat{\pi}$，比值得到 $\hat{s}$，再重构 $\hat{\theta}$。$s_{\text{denom}} = 1$。
- **Stacked (拼接模型: M4 $\pi$ + M3 $s$)**: 取 M4 之 $\hat{\pi}$ 与 M3 之 $\hat{s}$，按复合主键 `ROW_KEYS = ['seed', 'split', 'donor', 'scenario', 'delta', 'eta', 'depth_thin', 'adt_dropout', 'spot']` 严格 1:1 对齐（15,840 行无重复），组合生成 $\hat{\theta}$，继承 $s_{\text{denom}} = 1$。

### 3.3 已执行的自检断言结果
1. **行键唯一与 1:1 对齐**: M1–M4 各自 15,840 行均无重复主键；M3 与 M4 之 `cell_idx_hash` 100% 一致，无盲排错配。
2. **单纯形归一化**: 样本之 $\sum \pi = 1.0$ 与 $\sum \theta = 1.0$ 浮点误差 $< 10^{-12}$。
3. **树一致性**: 全量 79,200 行中 $\theta_{2c} + \theta_{2c+1} == \pi_c$ 全部满足。
4. **固定模型 $s$ 分母隔离**: M1/M2 全行保持 $s_{\text{denom}} = 0$ 与 $s_{\text{MAE}} = \text{NA}$。
5. **固定先验定点恢复核验**: 在真实条件比例 $s_c^{\text{true}} = 0.5$ 的 4,320 个单斑上，M1/M2 满足 $\theta_{\text{MAE}} == 0.5 \times \pi_{\text{MAE}}$（最大数值差值 $< 2.35 \times 10^{-5}$，完全源自 4 位小数格式化截断）。
   *(注：单斑实际总细胞数为 48 或 49 颗；在 S1 场景 $\delta = \pm 0.15$ 时，小类别离散抽取 5 颗细胞会导致真实值 $s^{\text{true}} = 2/5 = 0.40$ 的离散舍入)*。

## 6. 数据事实观察与未测限制

### 6.1 经验数据事实观察
1. **M2 固定先验在此基线数据上的数值表现**: 在当前基准中，M2 的 $\theta_{\text{MAE}}$ 保持在 0.026～0.043。这一现象源于本基线测试设定中，4 个粗大类中有 3 个（B、CD4 T、CD8 T）内部条件亚型比例真实值恒为 0.5，且唯一的 Mono 变动范围为 $\pm 0.3$。固定 $s_0=0.5$ 恰好吻合了多数未改变的类型。**这一数值表现受特定场景参数构造影响，不能外推为“不估计亚型比例在所有实验设计下均最优”的普遍结论**。
2. **拼接模型 Stacked 在当前表格中的表现**: 在名义测试与名义验证的所有 4 个场景下，Stacked 模型的 $\theta_{\text{MAE}}$ 均低于自由拟合模型 M4。
3. **技术噪声臂表现 (见 `tables_p1_all_arms.csv`)**: 测序深度稀释（1.0 $\to$ 0.25）对粗组成 $\pi_{\text{MAE}}$ 变化微弱（M4 在 Test S3 下各深度均为 0.0458～0.0465）；ADT 面板 30% 丢弃使 M2 和 M4 的 $\pi_{\text{MAE}}$ 均出现约 0.02 的增幅。
